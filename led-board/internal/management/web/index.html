Set up your departure board

Setup

    Choose a new password for this page. Anyone who knows the default password can change the board's settings, so you need a new one before you continue.

    Use 8 to 128 characters. The setup hotspot password stays DotMatrix.

    Tell the board how its LED panels are arranged and how they're wired to the Raspberry Pi. If you built the board with two 128×64 panels on a standard adapter, the settings are already correct.

    Look at the board

    Does the board look like this?

    Change the settings above, and then save again:

    • If nothing lights up, check that the panels have power and that the ribbon cable goes into each panel's input connector.
    • If a panel is blank or the picture repeats, check Panels in each chain and Columns per panel.
    • If the picture is split into bands or doubled, check Rows per panel.
    • If dots flicker or light up at random, increase GPIO slowdown.
    • If the panels connect through an Adafruit HAT or Bonnet, set Adapter wiring to match it.
    Colour 1 of 3

    Choose the colour shown on the board

    The board lights a pattern of dots in one colour. Panels don't all wire their colours in the same order, so the board learns its order from your answers.

    Look at the board

    The board restarts with the new colour order, and then shows three bands of colour.

    From left to right, are the bands red, green, and then blue?

    Choose the station whose departures the board shows, and how the board looks. You can change these, and every other setting, in Board settings.

    To keep the board's current connection, finish setup.

    Nearby networks

    Scan to find nearby Wi-Fi networks.

    You can also enter a network name manually. Some adapters cannot scan while the hotspot is active.

    Connect to Wi-Fi

    Use your country's two-letter code, such as GB, US or DE.
    The hotspot will disconnect while the board joins your network. Join the same Wi-Fi on this device, then open departureboard.local. If it cannot connect, the hotspot returns.

    Return to setup hotspot

    Forget the saved Wi-Fi network and start DepartureBoard again.

    Update settings

    Development builds come from each change to the code that passes automated tests. Nobody tries them on a board first, so they can stop the display working.
    The board checks within 30 minutes after this time, so that boards don't all check at once. An update never replaces a file that was edited on the board. If it would, the update stops and lists the file here. The board's settings are never changed by an update.

    Developer

    Root SSH access

    Add public keys to connect to your Pi as root. Each key grants full control of the Pi to whoever holds its matching private key.

    Connect from a terminal: ssh root@departureboard.local

    Paste the contents of your .pub files, one complete key per line. Keep private keys on your computer. To revoke a key, remove its line and save. Clearing this field removes all saved keys. Changes apply to new connections immediately.
