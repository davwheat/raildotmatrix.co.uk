Dot Matrix Font Builder

Drag across the board to select a line of text, type the characters it shows, and add them to a font. Import and export YAFF fonts, or export C and plain text.

—

Capture

The selection height becomes the glyph height, so select the full line height (including descender rows) to keep glyphs aligned on a common baseline.

Spaces in the text are ignored, so you can type the text as it appears on the board.

These characters aren't in this font yet. Select one to draw it, or use New glyph for any other character, such as £ or →.

Export

YAFF exports the selected font as one file. Import multiple .yaff files to load several fonts. Older JSON exports can also be imported.

Board bitmap

Paste one row per line. Use 1 or # for a lit LED and 0 or . for an unlit LED. Short rows are padded with unlit LEDs. Loading a new board keeps your fonts.

Edit glyph

Click or drag to turn LEDs on and off. Rings show the reference glyph.
